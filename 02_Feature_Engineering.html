🔧 Step 2: Feature Engineering¶

Goal: Transform raw columns into better features that capture domain knowledge and improve model performance.

We will:

  1. Create new numerical features from existing ones
  2. Encode ordinal columns as numbers
  3. One-hot encode categorical columns
  4. Apply log transform to the skewed target
  5. Save a clean, model-ready dataset

2.2 Fix Missing Values (same logic as EDA Step 9)¶

What we're doing: Apply the same cleaning pipeline so this notebook is self-contained.

In [2]:
# 'Feature absent' columns → replace NaN with 'None'
absent_cols = ['PoolQC', 'Alley', 'Fence', 'FireplaceQu', 'MiscFeature',
               'GarageType', 'GarageFinish', 'GarageQual', 'GarageCond',
               'BsmtQual', 'BsmtCond', 'BsmtExposure', 'BsmtFinType1', 'BsmtFinType2',
               'MasVnrType']
for col in absent_cols:
    if col in df.columns:
        df[col] = df[col].fillna('None')

# LotFrontage: group median by Neighborhood
df['LotFrontage'] = df.groupby('Neighborhood')['LotFrontage'].transform(
    lambda x: x.fillna(x.median()))
df['LotFrontage'] = df['LotFrontage'].fillna(df['LotFrontage'].median())

# Remaining numeric → global median
num_cols = df.select_dtypes(include=[np.number]).columns
df[num_cols] = df[num_cols].fillna(df[num_cols].median())

# Remaining categorical → 'Unknown'
cat_cols = df.select_dtypes(include='object').columns
df[cat_cols] = df[cat_cols].fillna('Unknown')

# Remove anomalous outliers (large house, tiny price)
df = df[~((df['GrLivArea'] > 4000) & (df['SalePrice'] < 200000))].reset_index(drop=True)

print(f'After cleaning: {df.shape}')
print(f'Missing values: {df.isnull().sum().sum()}')

2.3 Create New Features¶

What we're doing: Combine existing columns into richer signals based on domain knowledge about houses.

In [3]:
# ── Size features ─────────────────────────────────────────────────────────────
df['TotalSF']        = df['GrLivArea'] + df['TotalBsmtSF']           # total finished area
df['TotalPorchSF']   = (df['OpenPorchSF'] + df['EnclosedPorch'] +
                        df['3SsnPorch']   + df['ScreenPorch'])         # all porch types
df['TotalBath']      = (df['FullBath'] + 0.5 * df['HalfBath'] +
                        df['BsmtFullBath'] + 0.5 * df['BsmtHalfBath']) # weighted bathrooms

# ── Age features ──────────────────────────────────────────────────────────────
df['HouseAge']       = df['YrSold'] - df['YearBuilt']                 # age at sale
df['RemodAge']       = df['YrSold'] - df['YearRemodAdd']              # years since remodel
df['IsRemodeled']    = (df['YearRemodAdd'] != df['YearBuilt']).astype(int)
df['IsNew']          = (df['YrSold'] == df['YearBuilt']).astype(int)  # brand-new at sale

# ── Quality × Size interaction ────────────────────────────────────────────────
df['QualXArea']      = df['OverallQual'] * df['GrLivArea']            # strong interaction

# ── Has features (binary flags) ───────────────────────────────────────────────
df['HasPool']        = (df['PoolArea'] > 0).astype(int)
df['HasGarage']      = (df['GarageArea'] > 0).astype(int)
df['HasBasement']    = (df['TotalBsmtSF'] > 0).astype(int)
df['HasFireplace']   = (df['Fireplaces'] > 0).astype(int)

new_features = ['TotalSF','TotalPorchSF','TotalBath','HouseAge','RemodAge',
                'IsRemodeled','IsNew','QualXArea','HasPool','HasGarage','HasBasement','HasFireplace']
print('New features created:')
display(df[new_features].describe().round(2))

2.4 Encode Ordinal Columns¶

What we're doing: Convert quality ratings (text) to numbers that preserve order.

In [5]:
quality_map = {'None': 0, 'Po': 1, 'Fa': 2, 'TA': 3, 'Gd': 4, 'Ex': 5}

ordinal_cols = ['ExterQual', 'ExterCond', 'BsmtQual', 'BsmtCond',
                'BsmtExposure', 'HeatingQC', 'KitchenQual',
                'FireplaceQu', 'GarageQual', 'GarageCond',
                'PoolQC', 'Fence']

bsmt_exposure_map = {'None': 0, 'No': 1, 'Mn': 2, 'Av': 3, 'Gd': 4}
bsmt_finish_map   = {'None': 0, 'Unf': 1, 'LwQ': 2, 'Rec': 3, 'BLQ': 4, 'ALQ': 5, 'GLQ': 6}
garage_finish_map = {'None': 0, 'Unf': 1, 'RFn': 2, 'Fin': 3}
fence_map         = {'None': 0, 'MnWw': 1, 'GdWo': 2, 'MnPrv': 3, 'GdPrv': 4}
functional_map    = {'Sal': 1, 'Sev': 2, 'Maj2': 3, 'Maj1': 4,
                     'Mod': 5, 'Min2': 6, 'Min1': 7, 'Typ': 8}

for col in ['ExterQual','ExterCond','BsmtQual','BsmtCond','HeatingQC',
            'KitchenQual','FireplaceQu','GarageQual','GarageCond','PoolQC']:
    if col in df.columns:
        df[col] = df[col].map(quality_map).fillna(0).astype(int)

if 'BsmtExposure'  in df.columns: df['BsmtExposure']  = df['BsmtExposure'].map(bsmt_exposure_map).fillna(0).astype(int)
if 'BsmtFinType1'  in df.columns: df['BsmtFinType1']  = df['BsmtFinType1'].map(bsmt_finish_map).fillna(0).astype(int)
if 'BsmtFinType2'  in df.columns: df['BsmtFinType2']  = df['BsmtFinType2'].map(bsmt_finish_map).fillna(0).astype(int)
if 'GarageFinish'  in df.columns: df['GarageFinish']  = df['GarageFinish'].map(garage_finish_map).fillna(0).astype(int)
if 'Fence'         in df.columns: df['Fence']          = df['Fence'].map(fence_map).fillna(0).astype(int)
if 'Functional'    in df.columns: df['Functional']     = df['Functional'].map(functional_map).fillna(5).astype(int)
if 'CentralAir'    in df.columns: df['CentralAir']     = (df['CentralAir'] == 'Y').astype(int)
if 'PavedDrive'    in df.columns: df['PavedDrive']     = df['PavedDrive'].map({'N': 0, 'P': 1, 'Y': 2}).fillna(0).astype(int)

print('Ordinal encoding done.')
print(df[['ExterQual','KitchenQual','BsmtQual','FireplaceQu']].value_counts().head(5))

2.6 Log-Transform the Target Variable¶

What we're doing: We saw in EDA that SalePrice is right-skewed. Log-transforming it makes it normal, which improves linear model performance dramatically.

In [7]:
